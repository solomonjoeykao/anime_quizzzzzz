# 動漫宅會考

動漫猜謎派對網頁，包含聽歌、看圖和角色剪影三種題型。題庫儲存於專案中的 `questions.json`，上傳圖片儲存於 `img/`。

## 啟動

需啟動附帶的本機 Python 服務（Python 3，無需安裝額外套件）：

```sh
python3 server.py
```

接著瀏覽 `http://127.0.0.1:8000`。不要直接雙擊 HTML 或用一般靜態伺服器開啟，否則無法存取題庫與圖片檔案 API。YouTube 題目需要網路連線，影片也必須允許嵌入播放。

## 使用

1. 點「管理題庫」新增 YouTube 題目、動畫圖片或角色圖片。
2. 角色圖片會自動產生黑色剪影；遊戲中先顯示剪影，揭曉時切換到原圖。
3. 回到分類卡片開始遊戲。音樂題播放指定秒數後會自動暫停，也可手動暫停並揭曉答案。

圖片上傳時會製作適合網頁使用的版本（最長邊 1200 像素），並存到 `img/`；剪影題會同時保存原圖與剪影。題庫與圖片都是本機檔案，可備份或手動編輯 JSON。服務僅監聽本機 `127.0.0.1`，目前不同裝置不會同步。
